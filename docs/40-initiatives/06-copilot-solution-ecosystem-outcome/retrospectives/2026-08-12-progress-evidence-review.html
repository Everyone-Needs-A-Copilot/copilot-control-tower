Truthful language

What can—and cannot—be claimed

Supported: the program has accepted foundational transaction, conformance, content-input, native-invariant, signed-source-mechanics, and bounded security work.
Not supported: that the ecosystem is complete, released, safely fleet-propagated, behaviorally effective, safe under every entitlement race, clean-machine proven, or validated with a non-technical person.

This report records evidence only. It does not change task status, approve an owner decision, authorize publication, or authorize fleet mutation.
