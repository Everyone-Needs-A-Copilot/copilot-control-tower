M9 Stream-D/G (tasks 73, 76, sec agent): ADR-M9-003 REVIEWED, verdict ACCEPT
with one code fix + one flagged residual. Filled platform/windows/forced.rs
(HKLM\Software\Policies\ENAC\ControlTower, gated on dsregcmd-observed
domain-join/MDM enrollment via a pure decide(key, enrolled, hklm_value) fold,
never reads HKCU, dev-seam mirrors managed::forced's discipline) and
platform/windows/secret_store.rs (ports managed::secret_store's
endpoint-reference-only logic through super::forced -- SharedSecretStoreURL/
Tier only, never a secret value).

Security fix applied: enrollment probe must resolve dsregcmd via an absolute
%SystemRoot%\System32\dsregcmd.exe path, never a bare PATH lookup (was a
Medium 6.8/10 DREAD finding -- bare-name spawn is the same hijack class
ADR-M9-005 Q6 already forbids for the vendored CLI).

Residual flagged, NOT closed (Medium 5.8/10, not owner-gated -- no further
code fix in this app closes it): a local admin on an unmanaged/BYOD machine
can self-service domain-join a lab AD domain or register a free Azure AD
tenant, after which dsregcmd legitimately reports enrolled, indistinguishable
from genuine org enrollment. Structural asymmetry vs. macOS's
CFPreferencesAppValueIsForced (no self-service Apple-MDM-tenant equivalent
exists). Flagged for a future ADR, not invented here.

Scope finding on task 76: task text asked for actual Credential-Manager/DPAPI
store/retrieve via keyring, but the already-ratified PlatformSecretStore trait
(platform/mod.rs, ADR-M9-001) + credentials-and-boundary.md's ownership table
both say secret-VALUE resolution is the CLI's job, never Control Tower's
(invariant #1). Did NOT implement keyring-backed storage in this app crate --
would be new, uncalled capability contradicting ratified scope. Flagged for
@agent-ta if a future milestone genuinely wants to change that scope.

Full ADR text + DREAD scoring: tc wp get 57 (task 73). Verified: macOS cargo
test (692 lib tests) + all fitness/integration binaries green, clippy
--all-targets -D warnings clean, fmt --check clean. Windows compile/run NOT
claimed -- owner-gated, no Windows toolchain on this machine.
