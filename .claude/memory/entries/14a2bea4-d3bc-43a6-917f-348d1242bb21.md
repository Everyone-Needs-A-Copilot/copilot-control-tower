Connect experience (task 222): Bob's JTBD is 'my department's tools just run without me asking a colleague for a key I shouldn't hold' — the store is backstage, so the ideal count of 'Connect' moments on a member's screen is ZERO. Reframe: 'needs-connect' is not a legitimate state for a SHARED row; a shared thing is either Ready (you're on the team) or 'your team hasn't made this available' (actor = admin). Option b (GitHub-team-gated/OIDC) deletes the state; option a (claim-code + admin approval) must design around it as an ADMIN-owned approval Bob merely initiates, shown only when the CLI says it's actionable by him. HMW-3 (honest-degrade floor: no stderr, unreachable != revoked, named actor on every terminal state) is NOT an alternative — it's the floor under both and ships regardless of the fork.
