Self-service store provisioning (task 222): GitHub cannot be the IdP — it is OAuth-only for user login and exports no team claim, so a translator between GitHub team membership and Infisical authorization is unavoidable at every licence tier. Recommended architecture is a broker that ASSERTS (issues short-lived OIDC JWTs Infisical machine identities already trust via oidcDiscoveryUrl/boundClaims) rather than one that DISPENSES (mints Universal Auth clientId/clientSecret). Rationale: an identity-minting credential is transitively a secret-reading credential, so a minting broker has store-equivalent blast radius; an asserting broker holds only its own signing key and cannot create or widen a scope. Nothing store-related is at rest on the laptop, machine loss and offboarding collapse to one GitHub act, and G-12 closes by construction. B (mint) is NOT a stepping stone — it shares the hard half and only adds what B-prime exists to delete. Design: docs/05-security/self-service-store-provisioning.md
