M6-S1 (task 52): copilot update --json parse model lives in src-tauri/src/model/update.rs (collapsed single-file wire+domain+parse-boundary split, mirroring model::deprovision's precedent, NOT a separate update/ dir). Key fail-closed decisions: (1) signed missing on a changed[] entry defaults per-ENTRY to false/unsigned (never rejects the whole body) — the field-level analogue of deprovision's secrets_touched handling, since 'unsigned' is itself real actionable content the security banner needs. (2) op missing on a changed[] entry fails the WHOLE body closed to MissingSecurityField (mirrors doctor's checker id/severity/destructive treatment) — deliberately different from signed's per-entry default, because ChangeOp::Unchanged is a benign value an absent op must never silently become. (3) severity_trailer/shadowed_by stay Option<String> (nullable), never coerced to empty string — 'worst interpretation' of an absent trailer is deferred to the M6/S-E banner renderer, one layer above this parse boundary. (4) blocked[] (G-M6-4, open/unfrozen shape) modeled as an opaque BlockedEntry(serde_json::Value) wrapper — every element retained verbatim, never dropped, never reinterpreted; flagged for CLI freeze. UpdateParseOutcome::{Trusted(UpdateVerdict)|Unreadable(UpdateUnreadableReason)} is the typed surface the M6/S2 router consumes. Fixtures at src-tauri/fixtures/update/{corpus,invalid}/ + mock-cc gained an 'update' verb (default fixture applied-clean). 22 new tests, 463 prior tests unchanged (485 total green).
