CSE reconciliation pass (2026-07-13): claims.yaml corrections must read each claim's OWN truth condition before flipping status -- evidence-magnitude improvement alone does not imply passing (e.g. cli-soul-conformance stayed failing at 135/138 because xfail is a tracked violation, not a pass; agent-eval-coverage stayed failing at 6/16 because the claim requires EVERY agent). Collectors resolving a shared workspace root (collectors/paths.py resolve_copilot_root()) must match hardcoded prose paths in target docs (e.g. ECOSYSTEM.md) against ALL known root candidates, not just the locally-resolved one -- a single-candidate match silently produces vacuous 0/0 or over-flagged results instead of an honest number. Stale collector-output claims should be re-verified with a fresh collect before quoting, and superseded evidence attributed to an environmental cause (a path-fix newly seeing the real tree) rather than treated as a behavior regression when that's the true cause.
