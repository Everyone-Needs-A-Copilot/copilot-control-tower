T1 scaffold: pinned Tauri v2.11.5 (tauri crate) / @tauri-apps/cli 2.11.4 / @tauri-apps/api 2.11.1, vanilla-ts + Vite (no UI framework) for the popover. D-4 finding: Tauri 2.11.5's tray API supports template images natively (TrayIconBuilder::icon_as_template / TrayIcon::set_icon_as_template / set_icon_with_as_template, macOS-only, verified against tauri crate source src/tray/mod.rs) but has NO badge/overlay compositing primitive — set_icon always replaces the whole image wholesale, and set_title is text-only. Consequence: T6's render/glyph.rs must pre-composite the badge into the icon's pixel buffer before calling set_icon, not rely on a tray-level overlay.
