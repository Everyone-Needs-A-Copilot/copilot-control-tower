M3-S1 wizard state machine: phases modeled as Welcome->Detect->[Question]*->Materialize(phase_name)->Verify->Teach->Done, with Holding(ItConfigIncomplete{key}|WaitingForNetwork|VerifyFailed{status}). Done is reachable ONLY via WizardEvent::Verified(CliStatus) where status.is_healthy() is true (reuses M1's CliStatus, no new verdict computed). transition() in src-tauri/src/wizard/state.rs is a pure fn, exhaustively matched with no wildcard success arm.
