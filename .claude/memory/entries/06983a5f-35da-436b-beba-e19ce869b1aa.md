T8 (Copilot Control Tower M1): app command ACL — Tauri v2 skips capability enforcement for app-defined (non-plugin) commands entirely unless build.rs registers tauri_build::Attributes::new().app_manifest(AppManifest::new().commands([...])); without it, get_state/refresh_now were reachable regardless of capabilities.json. Wired AppManifest + tightened capabilities/default.json to [core:event:allow-listen, allow-get-state, allow-refresh-now], set withGlobalTauri:false. Verified via live app run (mock-cc) before/after — IPC still works.
