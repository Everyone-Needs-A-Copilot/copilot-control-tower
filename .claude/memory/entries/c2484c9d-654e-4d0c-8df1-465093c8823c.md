cse-bench (PRD-9 B-4/B-7): tasksdb collector reads Task Copilot stores via file:...?mode=ro SQLite URI (WAL-safe); catches sqlite3.Error per-repo into errors[] rather than crashing. 'reopened_count' has no direct schema support (no status-history table) so it is computed as a documented proxy: agent_log action='completed' entries whose task's current status != 'completed'. Symlinked product dirs (found: shared-docs -> knowledge-copilot) resolve to the same physical tasks.db and are de-duplicated by real path before scanning, reported under aliases_detected, to avoid double-counting. Collector registry is pkgutil-based auto-discovery (COLLECTOR_NAME + collect() in any collectors/*.py module) so B-5/B-6 collectors need zero edits to cse_bench.py. output/ is gitignored (regenerated history + -latest.json pointer), unlike cse-audit/output/ which is a committed one-off probe report.
