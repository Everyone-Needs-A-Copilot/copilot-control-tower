Control Tower M1 open contract gap (Decision D-1): doctor.schema.json emits only ONE top-level status + per-checker severity, with NO per-product/per-layer rolled-up status. The product-first dropdown needs per-product and per-layer badges. Resolution per ADR-M1-002: the app BUCKETS checkers by (product,layer) and shows the worst per-checker SEVERITY present (presentation, allowed) but must NOT synthesize a new 10-state status per layer (that is compute, forbidden). To render the full copy deck without computing, the CLI should emit per-product/per-layer status upstream in WS-A.
