cli-copilot's COPILOT_USAGE_LOG opt-in ledger cannot be enabled via cli-copilot/.env alone: the repo never calls python-dotenv's load_dotenv(), and pydantic-settings' env_file= only populates its own declared Settings() fields, not arbitrary os.environ keys. Verified empirically: .env-only setting produced no ledger line; shell-exporting the var produced one via the absolute binary path. Set COPILOT_USAGE_LOG=1 in cli-copilot/.env (gitignored, documents intent) + .env.example (tracked, documents the gap); durable enablement requires the owner to append 'export COPILOT_USAGE_LOG=1' to ~/.zshrc themselves (not done -- shell-profile edits are off-limits to this agent).
