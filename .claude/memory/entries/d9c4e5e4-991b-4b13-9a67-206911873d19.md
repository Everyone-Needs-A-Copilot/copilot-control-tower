M9 QA (task 80): mutation-testing the cheap text-scan fitness tests (inject the forbidden construct live, confirm the test fails, then revert) is the single highest-leverage QA move when the target platform can't be compiled/run at all -- it distinguishes a genuinely-guarding fitness test from a tautological one for near-zero cost. Also found via grep-before-trusting-the-matrix: a milestone's own architecture doc can list a mechanism as 'Resolved (conservative default)' when zero code implementing it actually exists yet (M9 row 8, notifications/toast wiring) -- always verify a 'designed' row against actual source (Cargo.toml deps + grep for the wiring), not just the doc's own status claim.
