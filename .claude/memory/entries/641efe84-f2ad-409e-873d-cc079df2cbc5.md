Local dev-env gotcha on this machine: $HOME/.local/bin/cc (the user's own copilot/cc CLI shim) shadows the system C compiler earlier in $PATH, breaking cargo's linker invocation with 'No such command ... symbols.o'. Workaround for any Rust build in this repo on this machine: CC=/usr/bin/cc CXX=/usr/bin/c++ RUSTFLAGS='-C linker=/usr/bin/cc' cargo build. Not baked into repo config (breaks other machines) — purely a local shell PATH fact.
