Faking git@alias:owner/repo SSH URLs for a deterministic test fixture: use GIT_SSH_COMMAND to intercept the transport (parse the trailing 'git-upload-pack <path>' arg, basename it, exec the real service against a local bare repo) rather than 'git config url.*.insteadOf' -- insteadOf also rewrites what 'git remote get-url origin' reports (documented git behavior), which silently breaks any test that checks origin-URL identity (e.g. onboard.py's wrong-origin classifier). insteadOf is fine ONLY for rows where you WANT get-url to show a mismatched value.
