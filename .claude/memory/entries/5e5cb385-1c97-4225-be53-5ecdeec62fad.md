routing/mod.rs: Actor{Bob,It}, ItSignalKind{DeprovisionTriggered,DeprovisionAmbiguous,AuthRevokedDeprovisionOffer}, ItSignal{kind, admin_contact:Option<String>} — content-free BY CONSTRUCTION (no identity/scope/org field exists on the type at all; a serde_json key-set test pins exactly {kind,admin_contact}). resolve_admin_contact() reads forced-domain-only "AdminContact" via managed::forced (user-domain value ignored+audited, matches existing AdminContact forced-domain-only fix already in the registry). route_credential_state(AuthState) -> CredentialRouting{BobReAuth, ItDeprovisionOffer(ItSignal)}: Expired->Bob (his own re-auth, his own data), Revoked->IT offer — and since model::failclosed::auth_state_from_wire already fails closed unknown->Revoked, an unrecognized auth state also routes to IT, never a fabricated "fine, re-sign-in".
