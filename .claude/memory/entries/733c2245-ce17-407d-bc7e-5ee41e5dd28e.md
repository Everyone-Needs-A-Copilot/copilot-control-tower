M3 QA (TASK-29): found+fixed a real cfg-gate bug in cli/path.rs — dev_override()'s reader fn (and resolve()'s call site) were #[cfg(debug_assertions)]-only, not #[cfg(any(debug_assertions, test))] like the DEV_OVERRIDE_ENV constant already was (M1's D1 fix only widened the constant, not the function that reads it). This silently broke CT_CLI_PATH for every test in the crate under 'cargo test --release --lib' (35 failures) even though 'cargo build --release'/'cargo clippy --release' stayed green (neither compiles test code) — M1 and M2 QA never actually ran 'cargo test --release', only build/clippy in release mode, so this was latent since M1. Fixed by widening dev_override()'s gate to match the constant; re-verified release strings scan still shows 0 CT_CLI_PATH (a genuine 'cargo build --release' has no cfg(test) either, so the fix doesn't reintroduce the override into a shipped binary). Residual, NOT fixed: cargo test --release (all targets, not just --lib) still fails one integration test (fitness_signin_seam_holds_no_secret's adversarial_leaked_field test) because cfg(test) never propagates to a lib compiled as an external integration-test's dependency — structural Cargo limitation, not a real bug; default (debug) 'cargo test' is the actually-specified verification path and is 100% green. Also found (NOT fixed, architectural, routed to @agent-me): ADR-M3-004's resumability is fully unit-tested in wizard/persistence.rs in isolation but save_checkpoint/load_checkpoint are never called anywhere outside its own tests — WizardIpcState::new() always starts fresh at NotStarted, so an interrupted wizard does NOT actually resume live, it restarts. And the managed silent progress spectator never streams live phase names in practice: managed_flow::run() is one single blocking spawn_blocking call with no Tauri event emission and no frontend poll loop for the managed phase, so Bob sees a static screen then a sudden jump to Done/Holding — materialize.rs's own doc comment claiming 'S6 forwards these as wizard-phase events' is stale/false, no such emit exists anywhere.
