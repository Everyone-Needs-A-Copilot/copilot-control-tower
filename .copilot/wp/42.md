## Verdict

**M6 = ACCEPT.**

The router is a genuine pure classifier — mutation-tested live to prove
(not merely assert) that: a wildcard match arm hiding a future unrouted
event is caught (FF-M6-A); routing a held-major event to `AskBob` — the
literal Alert Machine failure mode this milestone exists to close — is
caught (FF-M6-B); the router calling a parse-boundary function is caught
(FF-M6-D); and a security banner growing a `dismiss()` method is caught.
The one fitness function not live-mutated directly (FF-M6-C, content-free
`ItSignal`) is still supported by a proven-equivalent scanning technique
and a passing 13-variant value-level regression pin — flagged (D1) as
weaker evidence, not as a defect. A real personal item name was traced by
hand through all 4 hops of the live wiring path (parse → wire → route →
sink) and found structurally unable to reach the IT channel at any hop —
not merely absent by convention. Every named adversarial scenario (security
shadow, held-major, policy-denial, prune, auth expired/revoked, rollback,
unrecognized/malformed) routes exactly as architecture.md §9 and this
milestone's own memory record specify. The three honestly-deferred
"no live producer" claims (`notifications_denied`, dirty-WIP, the
router's own `cc update` path) were independently confirmed by grep, not
merely trusted from the module doc — and the one genuine, pre-existing
live `cc update --json` call site found (M3's wizard materialize step) was
traced and confirmed to be a wholly separate subsystem that never touches
the M6 router. The headless CDP sweep (8 fixture combinations) found 0
console errors, 0 forbidden-vocabulary hits (no approve/unblock/held-major/
dismiss anywhere in the rendered Bob or security-banner surfaces), silence
on the empty state, and exactly the expected single-button affordance on
every prompt/banner. 646/646 (debug) and 647/647 (release, the one benign
`#[cfg(not(debug_assertions))]` delta already documented by M4/M5 QA) tests
pass, deterministically, across two runs each; clippy/fmt/build are clean
in both profiles.
