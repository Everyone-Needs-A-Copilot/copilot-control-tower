## Rollback boundary (19.6 honesty requirement)

Reinstalling `0.5.6` — from either the verified `~/Applications-backup/` bundle or the archived `release/control-tower-0.5.6-c3a0455/` DMG, both confirmed recoverable above — rolls back the app and helper binary only. It does not and cannot reverse project changes that Python's bounded-assistant lifecycle already applied to a live project after explicit plan approval, because those changes are made directly to the target project's own git history/working tree, independent of which Control Tower binary is installed. This distinction is moot for the current release: no live selected project apply was authorized during this release run (steps 1–8), so there are no applied project changes for the rollback boundary to fail to cover. The app must not be described as able to correct the 30 currently-held projects (per 19.6); nothing in this release changes that.
