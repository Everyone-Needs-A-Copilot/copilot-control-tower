## Residual risk

1. The current framework resolver calls `resolve()` and checks `is_file()` but does not independently reject a future manifest path that escapes the repository root. The reviewed entries do not exploit this: their targets are in-repository regular files. The framework owner should add a containment check, reject escaping/symlink targets as policy requires, and add traversal/absolute-path/symlink fixtures before treating arbitrary manifests as safe. This is a system-level defense-in-depth gap, not a defect in the TASK-282 content.
2. Agent compliance with prose constraints remains probabilistic. Stream-D controlled behavioral evaluation must prove that the intended organization contribution appears without weakening factual discipline or human ownership.
3. Native Codex organization content is not loaded. Empty signer policy and the current single-foundation-plugin transaction mean unsigned organization plugins correctly do not materialize. This review does not claim or require dead parity files.
4. This review proves the current organization files do not contain personal material. Initiative-wide AC-12 still requires negative cross-tier write, leak, credential, and provenance evidence across Streams A, C, and D.
