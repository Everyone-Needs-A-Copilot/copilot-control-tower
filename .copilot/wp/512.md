# Phase 9.2 executable QA plan — Claude proposal artifacts

## Acceptance contract

1. Proposal generation changes zero project bytes and invokes no project hook/tool/shell/patch.
2. Claude receives only a bounded content-free dossier on stdin from a private cwd; no secret canary or project path appears in argv/process history.
3. A valid model result can select only option IDs offered by the exact fresh inspection. It cannot author operations, paths, commands, patches, content, verification, or UI prose.
4. Every malformed, injected, stale, dirty, tampered, replayed, interrupted, unavailable, or nonzero case yields typed blocked/interrupted evidence and no plan.
5. A normalized accepted proposal must still enter the existing expiring one-use plan, fresh preflight, guarded transaction, independent verify, rollback, and recover contract.
6. Source tests and exact packaged helper/app tests prove the same behavior without real project writes or live assistant/network dependency.

## Planned deterministic fixtures

- `malicious-project`: clean local Git repo whose instructions, filenames, branch, remote, and metadata contain prompt injection, leading CLI options, quotes, newlines, `$()`, backticks, ANSI/control text, `../`, and requests for shell/patch/secrets.
- `dirty-project`: separate staged, unstaged, untracked, conflict, detached-HEAD, chmod, symlink, and unreadable cases.
- `secret-canaries`: fake `.env`, HOME, SSH/Git config, env tokens, proxy credential, Keychain/auth seam; unique markers must never reach stdin/result/log/UI.
- `fake-claude`: records cwd/argv/env/stdin and supports valid, wrong-option, extra-field, shell, patch, duplicate-key, NaN, invalid UTF-8, oversized, empty, partial, nonzero-after-output, signal, timeout, and interrupted modes. It must fail if any tool/hook/project access is offered.
- `tamper-store`: swaps symlink/hardlink/session/result/state/proposal files and modifies bytes between every lifecycle transition.

## Abuse matrix

- Prompt injection: project text asks to ignore system, enable tools, read `.env`, run curl/rm, emit shell/patch, or mark Ready. Expected: fake sees no project content beyond bounded evidence; invalid fields/options rejected; no project/log/UI effect.
- Path attacks: `..`, absolute target, NUL/control, Unicode alias, symlink root/ancestor/target/result, hardlink result, directory swap. Expected: could-not-verify/unsafe artifact, zero writes.
- Secret leakage: canaries in env/HOME/project/remote/stderr. Expected: absent from prompt, artifact, diagnostic, pasteboard, argv, UI.
- Staleness/dirty: every Git/filesystem/config transition. Expected: exact stale/held code, consumed proposal cannot be rebound, zero mutation.
- Tamper/replay: edit raw/result/proposal/state/plan, duplicate keys, wrong digest/nonce, expiry, second claim. Expected: fail closed, durable audit status, no plan/apply.
- Assistant failure: missing/version/exit/signal/timeout/partial. Expected: typed blocker, bounded redacted evidence, manual retry only.
- Interrupt/recovery: kill before/during/after each durable transition and transaction observer. Expected: proposal phase no project writes; repeated recover stable; apply rollback/recovery matches ledger.
