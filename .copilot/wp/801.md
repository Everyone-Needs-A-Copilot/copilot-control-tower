Finding SEC-1 — CRITICAL — hostile Python startup executes before immutable verification and authority isolation
Exploit path:
1. scripts/provision-publisher-bootstrap.sh rejects selected release and shell variables, but does not reject or clear PYTHONPATH/PYTHONHOME/PYTHONSTARTUP/PYTHON*.
2. Its first complete materialization verifier is `/usr/bin/python3 - ...` in the inherited environment.
3. CPython imports sitecustomize from attacker-controlled PYTHONPATH before executing the verifier body.
4. That startup code can read same-user publisher authority prematurely, falsify or bypass verifier behavior, mutate the materialization, and allow unreviewed build code to run after the shell subsequently sources authority.
Evidence:
- `PYTHONPATH=<temp containing sitecustomize.py> /usr/bin/python3 -` returned status 0 and emitted CT_SITECUSTOMIZE_EXECUTED before the verifier body.
- Static dataflow: the forbidden-key loop at line 34 omits PYTHON*; the verifier at line 53 is not wrapped in env -i, unlike the isolated Git commands.
Impact: the claimed immutable-source/provenance boundary is bypassable before signing/notary authority becomes reachable.
Required mitigation: run every pre-boundary interpreter with an explicit empty environment and isolated mode where supported (for example env -i plus Python -I/-E), use fixed absolute tool paths, reject relevant startup/config variables at entry, and add a regression proving hostile sitecustomize/PYTHONPATH cannot execute or change the verifier result.

Finding SEC-2 — CRITICAL — TMPDIR becomes root shell code through the privileged heredoc
Exploit path:
1. TMPDIR is neither rejected nor normalized; scratch is created beneath `${TMPDIR:-/tmp}`.
2. `unsigned` and `approval` inherit that caller-controlled path.
3. The generated administrator script interpolates those paths inside single quotes (`ditto '${unsigned}' ...`, `cp '${approval}' ...`) without shell escaping.
4. A TMPDIR pathname containing a quote followed by command substitution breaks the intended quote; the injected command executes when the administrator-approved script runs as root.
Evidence:
- Exact quoting shape rendered with attacker path `/tmp/ct-'$(/usr/bin/printf CT_INJECTION_EXECUTED >&2)'/...`.
- `/bin/bash -c` emitted CT_INJECTION_EXECUTED before ditto failed, proving command execution during word expansion.
- Static dataflow: lines 38 -> 89 -> generated install heredoc -> privileged osascript.
Impact: a hostile caller environment can turn the attended administrator prompt into arbitrary root execution.
Required mitigation: remove caller-controlled strings from generated root shell source. Create scratch under a fixed, validated protected local path with a constrained character set, or pass values as separately escaped/validated argv to a fixed reviewed helper. Add exact-template quote, command-substitution, newline, whitespace, and metacharacter negative regressions.

Finding SEC-3 — HIGH — quarantine destination check/rename race can import rejected bytes into a protected tree
Exploit path:
1. The root script checks that the fixed quarantine path is absent and not a symlink.
2. It installs the new anchor and approval before invoking `/bin/mv REJECTED_APP rejected_quarantine`.
3. /Applications is root:admin mode 0775 on the reviewed Mac, so a concurrent logged-in admin can create the destination as a symlink after the check.
4. macOS `/bin/mv source symlink-to-directory` follows the destination and moves the source inside the symlink target, including a target below /Library/PrivilegedHelperTools.
Evidence:
- Hermetic race fixture created the absent-then-symlink state and ran the same `/bin/mv source destination` shape.
- mv returned 0 and `quarantine_symlink_import=YES` under the symlink target.
Impact: rejected attacker-controlled bytes can be imported into a protected trust-root subtree despite the contract and can persist when placed outside the exact signed canonical bundle. The reviewed exact entry is not directly selected as authority, but trust-root contamination violates the migration invariant and creates dangerous residual state.
Required mitigation: eliminate privileged quarantine movement, or use an atomic no-follow/no-replace rename primitive with directory file descriptors and verify the resulting inode/location. Do not use directory-following `/bin/mv`. Add a deterministic check-to-rename symlink/collision race regression that proves rejected bytes cannot enter any /Library subtree.
